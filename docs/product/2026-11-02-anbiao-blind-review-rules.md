# 暗标评审（暗标盲评）严格规则集

- 版本：2026-11-02
- 适用：工程建设招标投标中采用"暗标评审/暗标盲评"的技术标（勘察方案、设计方案、施工组织设计、监理大纲、工程总承包承包人建议书及实施方案等）
- 定位：投标人侧自查规则（BidCopilot 文件体检 / 生成 / 导出），不是评标规则，也不替代招标文件与评标委员会认定
- 来源分级：**法定** = 法律法规/部委规章原文；**地方** = 省市级规范性文件原文；**招标文件** = 单个项目最直接的约束；**行业** = 行业文章经验（仅作检查项提示，不作否决依据）
- 一句话结论：43 号令把"统一格式、隐藏特征、随机排序编号"定为交易中心的匿名处理义务；对投标人的直接约束来自招标文件与地方细则，多地明确"不按暗标要求编制"按**否决投标/无效投标**处理，且暗标部分**不予澄清、说明或补正**。

---

## 1. 效力层级与适用顺序

| 层级 | 文件 | 对投标人的效力 |
|---|---|---|
| 法律（草案，未生效） | 《招标投标法（修订草案）》第四十条：推行远程异地评标、推广评标中隐藏投标人信息 | 草案，不作为当前处罚依据；代表方向 |
| 行政法规 | 《招标投标法实施条例》第五十一条（否决投标 7 情形） | 现行有效；"未对实质性要求作出响应"是暗标违规被否决的上位依据 |
| 部委规章 | 《公共资源交易中心招标投标现场管理暂行办法》（2026 年第 43 号令，2027-01-01 施行） | 约束交易中心；第十三条明确匿名处理三项要求，投标人据此准备 |
| 部委规章 | 《招标投标领域信用管理暂行办法》（2026 年第 44 号令） | 5 类信用情形应否决投标（详见 D-05） |
| 地方规范性文件 | 青海、安徽、河南、锡林郭勒、蚌埠、呼和浩特等 | 直接写明"不满足暗标要求 → 否决投标/无效投标/不予澄清补正" |
| 招标文件 | 投标人须知前附表、评标办法、暗标编制要求 | **单项目最高优先**；格式参数（字体/字号/行距/页边距/页码/篇幅）以它为准 |

**适用顺序**：招标文件明示要求 ＞ 地方规范性文件 ＞ 部委规章 ＞ 行业惯例。招标文件要求不得低于法定要求；同一事项多处不一致时，按"更严格且可检测"者执行，并在提交前书面澄清。

**关键工程原则**：全国**没有**统一的暗标格式参数。河南要求"上 2.0cm、其余 2.5cm、固定 25 磅、宋体四号"，另有地方示例为"上 2.5cm、其余 2.0cm、固定 22 磅、标题三号正文四号"。因此规则引擎必须**先从招标文件解析参数**；解析不到时输出"待确认"，禁止用默认值代替。

## 2. 已核实的法规要点

### 2.1 43 号令（法定，交易中心义务）

- 发布：国家发展改革委、工业和信息化部、住房城乡建设部、交通运输部、水利部、农业农村部、商务部，2026 年第 43 号令；2026-06-12 第 32 次委务会议通过，2026-07-03 公布，**2027-01-01 施行**，共七章四十七条。
- 第十一条：交易中心配备终端，从依法组建的专家库**随机抽取**评标专家，不得透露项目等保密信息。
- 第十二条：按国家统一技术标准参与**远程异地评标**，为跨区域专家抽取、评标场地（工位）选取、专家身份验证、在线评标、评标报告签署、资料保存提供保障。
- 第十三条（暗标处理，原文要点）：
  1. **统一投标文件格式**；
  2. **隐藏投标人名称、标识、人名等特征信息**；
  3. **以招标文件规定的评分项为单位，对投标文件技术标部分进行随机排序和自动编号**。
- 第十四条：应用人工智能模型解析招标文件内容和投标文件响应度，辅助评标专家。
- 第二十三条：现场记录卷宗自形成之日起**至少保存十五年**。
- 第二十九条（投标人异常行为提醒）：交易中心发现投标人异常行为应提示评标委员会，包括**不同投标人的投标文件存在雷同内容**。

### 2.2 实施条例第五十一条（法定，否决投标）

有下列情形之一的，评标委员会应当否决其投标：（一）投标文件未经投标单位盖章和单位负责人签字；（二）投标联合体没有提交共同投标协议；（三）投标人不符合国家或者招标文件规定的资格条件；（四）同一投标人提交两个以上不同的投标文件或者投标报价（招标文件要求提交备选投标的除外）；（五）投标报价低于成本或者高于招标文件设定的最高投标限价；（六）**投标文件没有对招标文件的实质性要求和条件作出响应**；（七）投标人有串通投标、弄虚作假、行贿等违法行为。

暗标格式与去身份化要求通常写进"投标人须知/评标办法"，属于第（六）项的实质性要求；地方细则（如青海第三十条）已直接写明"不满足暗标要求 → 应当否决其投标"。

### 2.3 地方细则（地方，直接写明后果）

- **青海**（2024-06-11，省政府办公厅）：第三十条 对咨询服务方案、勘察方案、设计方案、施工组织设计、监理方案等采用"隐匿投标人名称、统一文字排版和插图形式"的暗标评审，由电子化交易平台统一随机编号；**投标人的投标文件不满足上述暗标评审要求的，评标委员会应当否决其投标**。
- **锡林郭勒盟**（2026-07-22，行署办公室实施方案）：技术标须统一页面大小和颜色、封面封底、字体、行距、页边距、页眉页脚；**不得出现招标文件统一要求以外的其他标识和能够识别投标人的信息**；不按暗标要求编制 → 评标委员会认定为**投标无效**；评标系统随机排序、随机生成编号。
- **安徽**（2026-09-23，交易集团答疑）：暗标内容应屏蔽投标人单位名称、简称、外文名称、特有标志、logo 及图案、人员姓名等；**不得出现明示或暗示投标人单位及个人信息的文字、图片、图表**。
- **河南**（省级平台标准文本要求）：技术标 PDF 须同时提供同版 Word；封面后即正文，**不得设目录、内封面及空白页**；页边距上 2.0cm、其余 2.5cm，**不编页码、不设页眉页脚**；正文行距固定 25 磅、左对齐、首行缩进 2 字符、不得有空格、段前段后 0；标题与正文宋体四号常规，图表宋体五号，**不得加粗、加色、倾斜、下划线**。
- **蚌埠**（2024-08-08）：暗标技术标**不予澄清、说明或者补正**。
- **呼和浩特**（2015）：早期口径——A4 白色复印纸、电脑绘制黑色打印、简写宋体四号黑色、页码小五号右下角、页眉页脚不得划线或作其他标识。
- **港区暗标评审办法**（公开转载，辖区待核实）：第九条列举不得出现——投标人名称/曾用名/简称、特有商标/徽标/标识、法定代表人及项目负责人等人员姓名/签字/印章、特有专利/工法/技术秘密名称、其他特殊标记；第十条要求招标文件明确不符合格式要求的处理方式（否决投标或量化扣分）。

### 2.4 行业经验（行业，仅作提示）

页眉页脚残留公司名/LOGO、文档属性作者单位、电子签章自带企业名、上传文件名含公司名、图片水印/设备铭牌/现场横幅/二维码、内部技术代号、修订批注与超链接残留等，被反复列为高频废标点。此类内容**不单独构成法定否决依据**，但一旦被招标文件列为暗标要求或平台格式检测命中，即落入 2.2 第（六）项。

## 3. 严格规则集

等级定义：**HARD** = 触发即应整改到零命中（多地按否决/无效处理）；**SOFT** = 可能扣分或需澄清，按招标文件处理；**INFO** = 仅提示人工复核。
证据要求：每条命中必须输出"文件 + 页/图层 + 命中片段 + 依据条款"，不得只给结论。

### 3.1 A 组：身份泄露（去标识化）

| A-02 | 商标、LOGO、徽标、图案 | HARD | 图片区域 OCR/视觉比对命中企业标识库；矢量图内含文字图层命中企业名；页眉页脚图片非空白 | 安徽答疑；锡林郭勒方案 |

## 4. 检测实现约束（工程口径）

1. **解析优先**：先从招标文件"投标人须知前附表 / 评标办法 / 暗标编制要求"解析出参数（纸张、边距、字体、字号、行距、页码、页眉页脚、目录、篇幅、文件格式、允许出现的内容），生成**项目级规则参数**；解析失败逐项报"待确认"，禁止套用默认值。
2. **多通道检测**：文本层、OCR（图片/表格/图表）、矢量图文字层、文档元数据、PDF 对象结构（注释/表单/附件/书签/可选内容层）、渲染排版测量，缺一不可。
3. **命中即定位**：输出文件、页码、坐标/片段、命中类型、依据条款、整改建议；同一位置多次命中合并展示。
4. **不越权结论**：产品只输出"命中 + 依据 + 建议人工复核"，不直接判定"必然废标"；HARD 项按招标文件/地方规定标注后果。
5. **零命中门槛**：A 组全部 HARD 项必须零命中才允许导出"暗标版"；B 组按招标文件参数全部通过；未通过时导出按钮阻断并给出整改清单。
6. **双向校验**：暗标版与明标版分开导出；暗标版禁止携带企业模板变量（企业名、logo、人员、业绩主体），模板渲染时强制替换为中性词。
7. **留痕**：每次检查记录规则版本、招标文件版本、命中证据摘要，便于事后申诉与复盘。

| 导出 | 已落地：导出前重开文件审计（A 组身份/自指/元数据），有残留即拦截；B 组格式差异随 `format_findings` 返回并在页边距上按模板修正 |
| 企业情报 | D-05 信用否决：对接失信被执行人/取消投标资格等数据，投标前预警 |
| 雷同自查 | 对应 43 号令 29 条(五)：跨投标人技术标雷同提示（已有 similarity 能力） |
| 审计 | 规则版本 + 招标文件版本 + 命中证据入审计链 |

## 6. 未核实与边界

1. **43 号令条款号**：第十三条（暗标匿名处理三项）来自公开转载与官方页面摘要，正式对外引用前应以国家发改委官网 PDF/OFD 原文复核条号与措辞。
2. **地方参数不可泛化**：河南（上 2.0/其余 2.5、25 磅、宋体四号）与另一地方示例（上 2.5/其余 2.0、22 磅、标题三号正文四号）不同，证明格式参数必须按项目解析。
3. **数字不采信**：原文所称"温州 400 个项目/241 亿""全省 450 个项目"等在不同来源中口径不一致（另有"241 个暗标项目/约 400 亿元"），仅作背景，不作为规则依据。
4. **适用范围**：暗标评审不是所有项目的默认要求；是否采用、哪些评分项采用，以招标文件为准。
5. **44 号令 5 情形**：来自公开报道，正式引用前应以原文复核。
6. **修订草案**：第四十条、第五十二条（15 年保存）尚未生效，不得作为当前否决依据。
7. **平台差异**：各地交易系统暗标模块（签章、格式检测、上传命名）实现不同，提交前须按平台操作指南与招标文件复核。
